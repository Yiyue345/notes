# 还是要学的基本语法

## 输出

输出使用`disp`：

```MATLAB
disp(A); % 输出 A
disp('Ciallo~');
```

格式化输出要用`fprintf`：

```MATLAB
fprintf('我要吃 %d 个苹果！', 100);
```

## 循环

如下所示

```MATLAB
for i = 1:5 % 1 到 5
    fprintf('第 %d 次 Ciallo~', i);
end
```

## 矩阵

像下面这样可以定义一个矩阵

```MATLAB
A = [3 1 2;  
2 1 2;  
1 2 3];
```

对于矩阵运算，比如数乘、相加、乘法，直接用符号就可以

```MATLAB
B = 2 * A;
C = A * B;
```

如果是逐元素操作，那就要加上`.`

```MATLAB
C = A .* B; % 两个矩阵对应元素分别相乘
D = A .^ 2; % D 中每个元素的值是 A 中对应元素的平方
```

如果要求 $|A|$ 和 $A^{-1}$：

```MATLAB
det(A);
inv(A);
```

## 函数图像

通过`figure`打开一个画图窗口，`grid on`可以显示网格

### 定义函数

可以像下面这样定义一个函数

```MATLAB
f = @(x) cos(tan(pi * x));
```

或者可以这样

```MATLAB
x = linspace(-2, 2, 1000);  
y = cos(tan(pi * x));
```

`x`是取 $[-2,2]$ 之间的 $1000$ 个点

### 画图

以上两种方法的画图方式如下

```MATLAB
fplot(f, [-2, 2]); % 定义了函数

plot(x, y); % 定义了 x 和 y
```

画完还可以用`xlabe()l`和`ylabel`()来分别给两个坐标轴设置标题，用`title()`来设置窗口标题，用`legend([...]);`来设置图例

如果要同时在坐标轴上显示多个函数图像，需要在画图前`hold on;`，画完再`hold off;`

如果想加文字说明，就要用`text(x, y, text)`来加文字
