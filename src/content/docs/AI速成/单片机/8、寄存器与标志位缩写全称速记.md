这份专门用来解决一个问题：**看到缩写能想起全称，看到全称能想起作用**。

51 单片机里很多名字不是随便起的，大部分缩写都有规律：

```text
T = Timer，定时器
I = Interrupt，中断
E = Enable，允许/使能
R = Run 或 Receive，运行/接收
S = Serial，串行
P = Priority 或 Port，优先级/端口
F = Flag，标志位
```

背的时候不要硬背一串字母，要按寄存器分类记。

## 2. PSW 程序状态字标志位

PSW 全称是 **Program Status Word**，中文叫**程序状态字寄存器**。它主要保存 CPU 运算后的状态。

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| CY | Carry Flag | 进位/借位标志 | 加法有进位或减法有借位时置1 |
| AC | Auxiliary Carry Flag | 辅助进位标志 | 低4位向高4位进位，常用于BCD调整 |
| F0 | User Flag 0 | 用户标志位0 | 给用户程序自定义使用 |
| RS1 | Register bank Select bit 1 | 工作寄存器组选择位1 | 与 RS0 配合选择 R0-R7 所属组 |
| RS0 | Register bank Select bit 0 | 工作寄存器组选择位0 | 与 RS1 配合选择工作寄存器组 |
| OV | Overflow Flag | 溢出标志 | 有符号数运算溢出时置1 |
| P | Parity Flag | 奇偶标志 | A中1的个数为奇数时置1 |

工作寄存器组选择：

| RS1 | RS0 | 当前工作寄存器组 | 地址范围 |
| --- | --- | --- | --- |
| 0 | 0 | 0组 | 00H-07H |
| 0 | 1 | 1组 | 08H-0FH |
| 1 | 0 | 2组 | 10H-17H |
| 1 | 1 | 3组 | 18H-1FH |

记忆：

```text
CY = Carry，和进位/借位有关。
OV = Overflow，和溢出有关。
RS = Register Select，选择工作寄存器组。
```

## 4. TCON 定时器/中断控制寄存器

TCON 全称是 **Timer Control Register**，中文叫**定时器控制寄存器**。它里面既有定时器控制位，也有外部中断控制位。

位序：

```text
TCON: TF1  TR1  TF0  TR0  IE1  IT1  IE0  IT0
```

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| TF1 | Timer 1 Overflow Flag | 定时器1溢出标志 | T1溢出后硬件置1 |
| TR1 | Timer 1 Run Control | 定时器1运行控制 | 置1启动T1，清0停止T1 |
| TF0 | Timer 0 Overflow Flag | 定时器0溢出标志 | T0溢出后硬件置1 |
| TR0 | Timer 0 Run Control | 定时器0运行控制 | 置1启动T0，清0停止T0 |
| IE1 | Interrupt 1 Edge Flag | 外部中断1请求标志 | INT1触发后置1 |
| IT1 | Interrupt 1 Trigger Type | 外部中断1触发方式控制 | 1为边沿触发，0为低电平触发 |
| IE0 | Interrupt 0 Edge Flag | 外部中断0请求标志 | INT0触发后置1 |
| IT0 | Interrupt 0 Trigger Type | 外部中断0触发方式控制 | 1为边沿触发，0为低电平触发 |

最常用写法：

```asm
SETB TR0    ; 启动定时器0
CLR TR0     ; 停止定时器0
SETB IT0    ; 外部中断0设置为边沿触发
```

记忆：

```text
TF = Timer Flag，定时器溢出标志。
TR = Timer Run，定时器运行控制。
IE = Interrupt Edge/Flag，这里表示外部中断请求标志。
IT = Interrupt Trigger，中断触发方式。
```

注意：这里的 `IE0/IE1` 是 TCON 里的外部中断请求标志；后面还有一个寄存器也叫 `IE`，它是中断允许寄存器。名字像，位置不一样。

## 5. TMOD 定时器方式控制寄存器

TMOD 全称是 **Timer Mode Register**，中文叫**定时器方式控制寄存器**。

位序：

```text
TMOD: GATE  C/T  M1  M0    GATE  C/T  M1  M0
       T1部分              T0部分
```

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| GATE | Gate Control | 门控位 | 控制定时器是否受外部 INT 引脚影响 |
| C/T | Counter / Timer Select | 计数/定时选择 | 0为定时器，1为计数器 |
| M1 | Mode Select bit 1 | 工作方式选择位1 | 与 M0 配合选择方式 |
| M0 | Mode Select bit 0 | 工作方式选择位0 | 与 M1 配合选择方式 |

工作方式：

| M1 | M0 | 工作方式 | 含义 |
| --- | --- | --- | --- |
| 0 | 0 | 方式0 | 13位定时/计数器 |
| 0 | 1 | 方式1 | 16位定时/计数器 |
| 1 | 0 | 方式2 | 8位自动重装 |
| 1 | 1 | 方式3 | 分拆方式，主要用于T0 |

常用设置：

```asm
MOV TMOD,#01H    ; T0方式1，定时器方式
MOV TMOD,#20H    ; T1方式2，常用于串口波特率
```

记忆：

```text
M = Mode，方式。
C/T = Counter/Timer，计数器/定时器二选一。
GATE = 门，决定是否受外部引脚“门控”。
```

## 6. IE 中断允许寄存器

IE 全称是 **Interrupt Enable Register**，中文叫**中断允许寄存器**。

位序：

```text
IE: EA  -  -  ES  ET1  EX1  ET0  EX0
```

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| EA | Enable All Interrupts | 中断总允许 | 1为开总中断，0为关总中断 |
| ES | Enable Serial Interrupt | 串行口中断允许 | 1为允许串口中断 |
| ET1 | Enable Timer 1 Interrupt | 定时器1中断允许 | 1为允许T1中断 |
| EX1 | Enable External Interrupt 1 | 外部中断1允许 | 1为允许INT1中断 |
| ET0 | Enable Timer 0 Interrupt | 定时器0中断允许 | 1为允许T0中断 |
| EX0 | Enable External Interrupt 0 | 外部中断0允许 | 1为允许INT0中断 |

常用写法：

```asm
SETB EA      ; 开总中断
SETB ET0     ; 允许定时器0中断
SETB EX0     ; 允许外部中断0
SETB ES      ; 允许串口中断
```

记忆：

```text
E = Enable，允许。
A = All，总。
S = Serial，串口。
T = Timer，定时器。
X = eXternal，外部。
```

所以：

```text
ET0 = Enable Timer 0，允许定时器0中断。
EX0 = Enable External 0，允许外部中断0。
ES = Enable Serial，允许串口中断。
```

注意：`EA` 有两个常见含义：

| 场景 | EA含义 |
| --- | --- |
| IE寄存器中的 EA | Enable All Interrupts，中断总允许 |
| 单片机引脚 EA | External Access，外部程序存储器访问控制 |

考试中如果说“IE中的EA”，就是中断总允许；如果说“EA引脚”，就是外部访问控制引脚。

## 7. IP 中断优先级寄存器

IP 全称是 **Interrupt Priority Register**，中文叫**中断优先级寄存器**。

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| PS | Priority of Serial Interrupt | 串行口中断优先级 | 1为高级，0为低级 |
| PT1 | Priority of Timer 1 Interrupt | 定时器1中断优先级 | 1为高级，0为低级 |
| PX1 | Priority of External Interrupt 1 | 外部中断1优先级 | 1为高级，0为低级 |
| PT0 | Priority of Timer 0 Interrupt | 定时器0中断优先级 | 1为高级，0为低级 |
| PX0 | Priority of External Interrupt 0 | 外部中断0优先级 | 1为高级，0为低级 |

记忆：

```text
P = Priority，优先级。
S = Serial，串口。
T = Timer，定时器。
X = eXternal，外部中断。
```

所以：

```text
PX0 = Priority External 0，外部中断0优先级。
PT0 = Priority Timer 0，定时器0优先级。
PS = Priority Serial，串口优先级。
```

## 8. 串口相关寄存器 SCON、SBUF、PCON

### 8.1 SCON 串行口控制寄存器

SCON 全称是 **Serial Control Register**，中文叫**串行口控制寄存器**。

位序：

```text
SCON: SM0  SM1  SM2  REN  TB8  RB8  TI  RI
```

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| SM0 | Serial Mode bit 0 | 串口工作方式选择位0 | 与SM1配合选择方式 |
| SM1 | Serial Mode bit 1 | 串口工作方式选择位1 | 与SM0配合选择方式 |
| SM2 | Serial Mode bit 2 / Multiprocessor Communication Enable | 多机通信控制位 | 多机通信中过滤地址帧/数据帧 |
| REN | Receiver Enable | 允许接收 | 1为允许串口接收 |
| TB8 | Transmit Bit 8 | 发送第9位数据 | 方式2/3中发送第9位 |
| RB8 | Receive Bit 8 | 接收第9位数据 | 方式2/3中接收第9位 |
| TI | Transmit Interrupt Flag | 发送中断标志 | 发送完成后硬件置1 |
| RI | Receive Interrupt Flag | 接收中断标志 | 接收完成后硬件置1 |

常用设置：

```asm
MOV SCON,#50H
```

`50H = 0101 0000B`，表示：

```text
SM0=0，SM1=1：串口方式1
REN=1：允许接收
```

### 8.2 SBUF 串行数据缓冲寄存器

SBUF 全称是 **Serial Buffer Register**，中文叫**串行数据缓冲寄存器**。

| 操作 | 含义 |
| --- | --- |
| 写 SBUF | 启动发送 |
| 读 SBUF | 读取接收到的数据 |

示例：

```asm
MOV SBUF,A       ; 发送A中的数据
MOV A,SBUF       ; 读取接收到的数据
```

### 8.3 PCON 电源控制寄存器

PCON 全称是 **Power Control Register**，中文叫**电源控制寄存器**。

| 位名 | 英文全称 | 中文含义 | 作用 |
| --- | --- | --- | --- |
| SMOD | Serial Mode Baud Rate Double | 串口波特率倍增位 | 置1时串口方式1/2/3波特率加倍 |
| GF1 | General Flag 1 | 通用标志1 | 用户自定义 |
| GF0 | General Flag 0 | 通用标志0 | 用户自定义 |
| PD | Power Down | 掉电方式 | 进入掉电模式 |
| IDL | Idle Mode | 空闲方式 | 进入空闲模式 |

记忆：

```text
SCON = Serial Control，串口控制。
SBUF = Serial Buffer，串口缓冲。
REN = Receiver Enable，允许接收。
TI = Transmit Interrupt，发送完成标志。
RI = Receive Interrupt，接收完成标志。
SMOD = Serial Mode，常用于波特率加倍。
```

## 13. 按题目反推缩写的技巧

### 看到“允许”

优先找 `E`：

```text
EA：总允许
EX0：允许外部中断0
ET0：允许定时器0中断
ES：允许串口中断
REN：允许接收
```

### 看到“优先级”

优先找 `P`：

```text
IP：中断优先级寄存器
PX0：外部中断0优先级
PT0：定时器0优先级
PS：串口优先级
```

### 看到“启动定时器”

找 `TR`：

```text
TR0=1：启动T0
TR1=1：启动T1
```

### 看到“溢出”

找 `TF`：

```text
TF0：T0溢出标志
TF1：T1溢出标志
```

### 看到“串口收发完成”

找 `RI/TI`：

```text
RI：Receive Interrupt，接收完成
TI：Transmit Interrupt，发送完成
```

## 14. 考前最小背诵版

```text
IE 是 Interrupt Enable，中断允许寄存器。EA 是总允许，EX0/EX1 允许外部中断，ET0/ET1 允许定时器中断，ES 允许串口中断。

IP 是 Interrupt Priority，中断优先级寄存器。PX0/PX1 设置外部中断优先级，PT0/PT1 设置定时器优先级，PS 设置串口优先级。

TCON 是 Timer Control，定时器控制寄存器。TR0/TR1 控制定时器运行，TF0/TF1 是定时器溢出标志，IT0/IT1 设置外部中断触发方式，IE0/IE1 是外部中断请求标志。

TMOD 是 Timer Mode，定时器方式控制寄存器。C/T 选择定时或计数，M1/M0 选择工作方式，GATE 是门控位。

SCON 是 Serial Control，串口控制寄存器。REN 允许接收，TI 是发送完成标志，RI 是接收完成标志，SM2 用于多机通信。

SBUF 是 Serial Buffer，写 SBUF 发送数据，读 SBUF 接收数据。
```
