# 一、考试形式和复习总方向

课程总结里给出的总评结构是：

| 项目 | 比例 |
|---|---:|
| 平时成绩 | 35% |
| 实验成绩 | 15% |
| 期末考试 | 50% |

期末复习建议里最重要的几句话可以概括成：

1. 重点复习课程目标 1、课程目标 2、课程目标 3。
2. 结合教学课件和教材典型例题，掌握计算、分析、设计方法。
3. 总结作业、测验、课堂练习中出现的问题。
4. 先导基础不能丢：进制转换、真值和补码相互转换。

这说明这门课不是只背概念，考试很可能以：

```text
基础概念 + 计算题 + 分析题 + 设计题
```

组合出现。

# 二、课程目标 1：运算器和存储系统

课程总结列出的课程目标 1 主要知识点有：

1. 定点加减法运算。
2. 定点乘法运算。
3. 浮点加减法运算。
4. 主存的组织及与 CPU 的连接。
5. 并行主存系统。
6. 高速缓冲存储器 Cache。

这部分的特点是：**计算题多，步骤题多，容易因为位数、地址位、块号、标记字段写错而丢分。**

建议复习顺序：

```text
进制与补码
→ 定点补码加减和溢出判断
→ 定点乘法
→ 浮点加减
→ 主存芯片扩展与地址译码
→ 并行主存性能
→ Cache 地址划分和命中率
```

其中课堂截图中前几周大量出现：

- 原码、反码、补码。
- 真值与机器数转换。
- 补码加减法。
- 浮点数规格化、对阶、尾数运算、舍入。

这说明先导基础不是“顺便看看”，而是后面定点、浮点运算题的入口。

# 三、课程目标 2：指令系统、CPU 数据通路和微程序

课程总结列出的课程目标 2 主要知识点有：

1. 指令格式。
2. 寻址方式。
3. 指令格式分析设计。
4. CPU 组成、指令周期及数据通路。
5. 微程序控制器。

这部分常见考法有两类。

第一类是**指令格式分析题**：

```text
给出指令字长、操作码字段、地址码字段、寻址方式字段
→ 问可以表示多少条指令
→ 问可寻址范围是多少
→ 问通用寄存器数量是多少
→ 问扩展操作码怎么设计
```

第二类是**数据通路和控制信号分析题**：

```text
给出 CPU 模型
→ 分析 lw、sw、beq、addi、add、sub 等指令
→ 写出每个节拍完成的数据传送
→ 写出对应控制信号
```

课堂截图中 4 月中下旬明显集中出现：

- 取指数据通路。
- `lw` 指令数据通路。
- `sw` 指令数据通路。
- `beq` 指令数据通路。
- `addi`、`add`、`sub` 指令数据通路。
- 多周期时序图。
- 微程序控制器、时序发生器、微命令字段。

所以这部分不能只背定义，必须会按图走数据流。

# 四、课程目标 3：流水线、互连网络和并行计算

课程总结列出的课程目标 3 主要知识点有：

1. 线性流水线性能分析。
2. 非线性流水线调度。
3. SIMD 互连网络。
4. 静态网络。
5. 动态网络。
6. 程序划分和调度。
7. 并行计算机模型。

这部分的共同特点是：**公式题和过程题多。**

要会：

- 画线性流水线时空图。
- 求吞吐率、加速比、效率。
- 根据预约表求延迟禁止表、冲突向量、状态转换图、最优调度。
- 写 Cube、PM2I、Shuffle、Butterfly 等互连函数。
- 根据静态网络结构计算并行执行时间。
- 区分 BSP 和 PRAM 模型计算时间公式。

课堂截图中 5 月以后大量出现系统结构教材页、流水线、互连网络、BSP/PRAM 相关内容，说明课程后半段也在考试范围内，不要只复习前面的计算机组成。

# 五、最推荐的复习路线

如果时间紧，按下面顺序复习：

## 第一轮：把能直接拿分的公式和模板背下来

重点看：

- 补码加减与变形补码溢出判断。
- 浮点加减步骤。
- Cache 地址划分模板。
- 并行主存公式。
- 流水线性能公式。
- BSP/PRAM 公式。

这一轮目标不是深挖原理，而是保证看到题知道从哪里下手。

## 第二轮：练过程题

重点练：

- 定点乘法位数和结果位数。
- 主存芯片扩展地址范围。
- Cache 映射题。
- 指令格式设计题。
- CPU 数据通路节拍分析。
- 微指令字段编码。
- 非线性流水线状态图。

这些题容易因为漏一步丢分，必须按固定步骤写。

## 第三轮：整理易错点

建议专门检查：

```text
补码小数和补码整数的分隔符
符号位是否参与运算
浮点对阶方向
Cache 是字编址还是字节编址
主存容量单位是 bit 还是 Byte
直接映射中的标记、行号、块内偏移位数
扩展操作码是否给长码留下扩展标志
流水线时间是否含装入时间
非线性流水线延迟禁止表是否漏项
```

# 七、总复习提醒

这门课最容易出现的问题不是“完全不会”，而是：

```text
知道概念，但不会套步骤；
知道公式，但变量含义混；
会算一半，但地址位数、结果位数、符号位写错；
看得懂图，但写不出每个节拍的数据通路。
```

所以复习时不要只看结论，要特别训练“过程表达”。考试答题时，即使最终数值有小错，过程完整也更容易拿步骤分。
