这部分说明老师非常重视基础编码和运算过程。不要只会背“补码定义”，要会从真值写机器数，也要会从机器数还原真值。

重点复习：

```text
原码/反码/补码转换
补码加减法
变形补码溢出判断
浮点数对阶、尾数运算、规格化、舍入
IEEE 754 基本字段含义
```

教材查阅：第 18-29 页。

# 五、4 月中下旬：CPU 数据通路和控制信号

课堂截图中明显出现：

- 单总线结构 CPU。
- 取指数据通路。
- `lw` 指令数据通路。
- `sw` 指令数据通路。
- `beq` 指令数据通路。
- `addi`、`add`、`sub` 指令数据通路。
- 多周期时序。
- 每个节拍对应的数据传送。

这部分很可能考：

```text
给出CPU模型，分析某条指令执行过程
写出每个节拍完成的微操作
写出关键控制信号
```

重点复习：

```text
取指阶段公共操作
lw：内存到寄存器
sw：寄存器到内存
beq：比较后选择PC
addi：寄存器加立即数写回
R型指令：两个寄存器进ALU，结果写回寄存器
```

教材查阅：指令系统第 149-162 页；CPU 和数据通路第 186-217 页。

$$

# 九、根据课堂截图推测的高频题型

## 1. 补码/浮点计算题

可能形式：

```text
给定 x、y，求补码加减结果并判断溢出。
给定浮点数，完成加减运算过程。
给定十进制数，写 IEEE 754 或规格化浮点形式。
```

## 2. Cache 地址划分题

可能形式：

```text
给定主存容量、Cache容量、块大小和映射方式，
求标记、行号/组号、块内地址位数。
```

## 3. 指令数据通路题

可能形式：

```text
给定 CPU 数据通路图，分析 lw/sw/beq/addi/add/sub 的执行流程。
```

## 4. 微指令编码题

可能形式：

```text
给定若干微命令分组，求微指令操作控制字段位数。
或根据数据通路写某条机器指令的微操作序列。
```

## 5. 流水线性能和调度题

可能形式：

```text
给定流水线段数和任务数，求总时间、吞吐率、加速比、效率。
给定预约表，求延迟禁止表、冲突向量、状态转换图、最优调度。
```

## 6. 并行计算模型公式题

可能形式：

```text
给定 m、N、t_multi、t_add、g、h、l，
分别求 BSP/PRAM 时间和加速比。
```

# 十、最后复习建议

如果只看课堂截图，会觉得内容很多、很散；但课程总结已经把考试范围收束到三个课程目标。最稳的复习方法是：

```text
课程总结列点 = 考试范围
课堂截图反复出现 = 高频题型
教材例题/作业题 = 具体解法模板
```

所以考前不要漫无目的从头翻书，优先围绕这些题型练：

1. 补码与浮点运算。
2. 主存和 Cache。
3. 指令格式与数据通路。
4. 微程序控制。
5. 流水线和互连网络。
6. BSP/PRAM 并行模型。
