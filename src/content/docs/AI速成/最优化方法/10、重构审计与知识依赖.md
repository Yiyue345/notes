## 知识依赖

```text
代数运算
  ├─ 向量、矩阵、内积、范数
  │    ├─ 位移与误差 ──> 迭代停止条件
  │    └─ 方向导数 ──> 下降方向 ──> 线搜索
  ├─ 导数、偏导、梯度
  │    ├─ 一阶泰勒 ──> Armijo / Wolfe
  │    └─ 驻点条件 ──> 无约束最优性
  ├─ 二阶导数、Hessian、正定性
  │    ├─ 二阶泰勒 ──> 牛顿法
  │    ├─ 二次型 ──> 精确线搜索 / 共轭方向
  │    └─ 曲率 ──> 局部极小判断
  ├─ 凸集、凸函数
  │    ├─ 局部最优 = 全局最优（凸问题）
  │    └─ 线性规划可行域 / 凸二次规划
  ├─ 线性方程与消元
  │    ├─ 单纯形换基
  │    ├─ 牛顿方程
  │    └─ 等式约束 QP 子问题
  └─ 约束边界、可行方向
       └─ 拉格朗日乘子 ──> KKT ──> 有效集增删
```

推荐学习顺序是 01 → 02 → 03 → 04 → 05。02 只依赖 01 的向量、线性式和凸集直觉；03 必须先知道方向导数；04 必须先知道线搜索；05 必须先知道梯度、可行方向和线性方程。06～09 都是对这些章节的练习、考试或速查入口。

## 理论、考试与实验的版本边界

| 概念 | 理论/考试资料 | 当前真实实验代码 | 不应混用之处 |
|---|---|---|---|
| 一维线搜索 | 进退、黄金分割、三点二次插值、Armijo/Wolfe | 实验一含进退、黄金分割、课堂三点插值、Armijo；`c1=1e-4`、`rho=0.5` | 代码的三点插值失败时直接报错，不自动伪装成黄金分割成功 |
| 最速下降 | 正定二次题常用精确线搜索 | 实验二有 $Q$ 时精确线搜索，否则 Armijo | 不能把非二次问题也套 $-g^Td/(d^TQd)$ |
| 牛顿法 | 原卷只写“牛顿法”；解析按标准迭代解 $Hd=-g$，取单位步长 | 实验二同样固定 $\alpha=1$ | 梯度小只说明一阶驻点残差小，不保证接近某个驻点或最小值 |
| 共轭梯度 | 往年卷与老师作业使用 FR | 实验三使用 PRP+，并每 $n$ 步重启、非下降时重启 | FR 的有限步性质不能直接搬给实验三的非线性 PRP+ |
| 拟牛顿 | 教材介绍 DFP/BFGS 逆 Hessian 更新 | 实验三更新逆 Hessian 近似 $H$，配 Armijo；曲率条件不满足时跳过更新 | 先确认更新的是 $H$ 还是 $B=H^{-1}$ 再套公式 |
| 有效集 | 统一写 $c_i(x)\ge0$ | 实验四固定为 $Ax\ge b$ | 若改写成 $g_i\le0$，乘子符号与拉格朗日函数必须一起改 |
