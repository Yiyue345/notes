| 要解决的问题 | 公式或判据 | 使用前检查什么 |
|---|---|---|
| 向量有多大？ | $\|x\|_1=\sum_i|x_i|$；$\|x\|_2=\sqrt{\sum_i x_i^2}$；$\|x\|_\infty=\max_i|x_i|$ | 不要把三种范数当成一个值 |
| 向某方向走会下降吗？ | $f'(x;d)=\nabla f(x)^Td$ | $f$ 在该点可微；若内积小于零，$d$ 是严格下降方向 |
| 用二阶信息估算附近函数？ | $f(x+s)\approx f(x)+g^Ts+\tfrac12s^THs$ | 仅为局部近似；$g=\nabla f(x),H=\nabla^2 f(x)$ |
| 一阶展开 | $f(x+\alpha d)=f(x)+\alpha g^Td+o(|\alpha|)$ | 固定 $d$，令 $\alpha\to0$；注意余项 |
| 二阶展开 | $f(x+\alpha d)=f(x)+\alpha g^Td+\frac{\alpha^2}{2}d^THd+o(\alpha^2)$ | $f$ 在附近二阶连续可微；不能漏掉第二个 $\alpha$ |
| 判断二维对称 Hessian 正定 | $H=\begin{pmatrix}a&b\\b&c\end{pmatrix}$，$a>0,\ ac-b^2>0$ | 仅适用这里的二维对称形式；高维用顺序主子式等方法 |
| 判断凸函数 | $f(tu+(1-t)v)\le tf(u)+(1-t)f(v)$ | 定义域须凸；$t\in[0,1]$，任意 $u,v$ |
| 范数的凸性 | $\|tu+(1-t)v\|\le t\|u\|+(1-t)\|v\|$ | 用三角不等式与绝对齐次性；不能用个例代替证明 |
| 更新迭代点 | $x_{k+1}=x_k+\alpha_kd_k$ | 区分搜索方向和步长；步长通常取正 |
| 正定二次函数精确线搜索 | $\alpha_*=-\frac{g^Td}{d^TQd}$；当 $d=-g$，$\alpha_*=\frac{g^Tg}{g^TQg}$ | $f=\frac12 x^TQx+c^Tx+\text{常数}$，$Q\succ0$，$d$ 是下降方向 |
| 黄金分割 | $r=(\sqrt5-1)/2\approx0.618$；$c=b-r(b-a),\ d=a+r(b-a)$ | 单峰函数、有效包含极小点的区间；区分 $c,d$ 的次序 |
| 三点抛物线插值 | 用三个 $(\alpha_i,\phi_i)$ 拟合 $q=A\alpha^2+B\alpha+C$，候选点 $-B/(2A)$ | $A>0$ 且候选点在允许区间内；还须评价真实函数 |
| Armijo | $f(x+\alpha d)\le f(x)+c_1\alpha g^Td$ | $0<c_1<1$，$g^Td<0$；缩步长不能修复非下降方向 |
| 弱 Wolfe 曲率条件 | $\nabla f(x+\alpha d)^Td\ge c_2g^Td$ | 常与 Armijo 合用，$0<c_1<c_2<1$ |
| 最速下降 | $d_k=-g_k$ | 欧氏范数下最陡下降方向；$g_k\ne0$ |
| 牛顿方向 | $H_kd_k=-g_k$ | $H_k$ 应可解；正定保证 $d_k$ 下降，非正定需修正 |
| 逆 BFGS | $M_+=(I-\rho sy^T)M(I-\rho ys^T)+\rho ss^T$，$\rho=1/(y^Ts)$ | $s=x_+-x,y=g_+-g$，正定保持需 $y^Ts>0$ 等条件 |
| 逆 DFP | $M_+=M+ss^T/(s^Ty)-Myy^TM/(y^TMy)$ | $M$ 为**逆** Hessian 近似，注意两个分母不为零 |
| FR | $\beta_k^{FR}=\frac{g_{k+1}^Tg_{k+1}}{g_k^Tg_k}$ | 分母非零，题目指定 FR 时不得替换成 PRP |
| PRP 与 PRP+ | $\beta_k^{PRP}=\frac{g_{k+1}^T(g_{k+1}-g_k)}{g_k^Tg_k}$；PRP+ 取 $\max(0,\beta^{PRP})$ | 与 FR 不同；非线性实现还需合理线搜索与重启 |
| KKT 驻点 | $\nabla f+\sum_i\lambda_i\nabla g_i+\sum_j\mu_j\nabla h_j=0$ | 在 $g_i\le0$ 且 $L=f+\sum\lambda_i g_i+\sum\mu_jh_j$ 约定下使用 |
| KKT 其余三组 | $g_i\le0,h_j=0;\ \lambda_i\ge0;\ \lambda_i g_i=0$ | 互补松弛不是说两者均为零；KKT 的必要性与充分性有不同条件 |
| 有效集最大可行步长 | $\alpha=\min\left(1,\min_{i\notin W,\,a_i^Tp>0}\frac{b_i-a_i^Tx}{a_i^Tp}\right)$ | 这里约束统一 $a_i^Tx\le b_i$；只对分母正的非活动约束比值 |
| 单纯形法检验数 | $\sigma_j=c_j-c_B^TB^{-1}a_j$ | 在**极小化**问题且该定义下，负的有改善可能；最大化正的有改善可能 |

### 怎样分清“必要条件”和“充分条件”？

这是常见考试错误，不属于可省略的细枝末节。对于可微**无约束**问题，局部最优点必满足 $\nabla f(x)=0$（必要）。但梯度零不保证是最低点。对于凸可微函数，梯度零才推出全局最优。对于一般可微有约束问题，最优点满足 KKT 的必要性还需约束规范条件；而在凸目标、凸不等式、仿射等式的相应可微条件下，一个可行 KKT 点是全局最优。

### 最好记住的三条检查规则

做数值题写完结果后，**看梯度、看可行性、看函数值**：驻点要检验梯度是否近零；约束题必须代回每一条原约束；下降算法应核对是否下降（必要时还要核对终止条件）。证明题要说明是哪一个数学性质支撑了关键的不等号。代码题要确认 FR、PRP、PRP+、直接 Hessian 与逆 Hessian 近似这些名称没有混用。
