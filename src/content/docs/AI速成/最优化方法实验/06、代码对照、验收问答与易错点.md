## 二、常见 Python 写法与数学含义

| 代码 | 数学含义 | 容易误解的地方 |
|---|---|---|
| `g @ d` | $g^Td$ | 向量内积，返回标量 |
| `Q @ x` | $Qx$ | 矩阵乘向量，不是逐元素乘法 |
| `np.outer(s, y)` | $sy^T$ | 外积，得到矩阵 |
| `np.linalg.norm(g)` | 默认向量二范数 | 不是各分量直接相加 |
| `np.linalg.solve(Q, -g)` | 解 $Qd=-g$ | 不显式构造 $Q^{-1}$ |
| `np.linalg.eigvalsh(Q)` | 对称矩阵特征值 | 本代码用于曲率检查 |
| `np.eye(n)` | 单位矩阵 $I$ | 不是所有元素都为 1 |
| `np.block(...)` | 拼接分块矩阵 | 有效集 KKT 方程的系数矩阵 |
| `np.r_[...]` | 拼接向量 | KKT 右端由 $-g$ 与零向量组成 |
| `np.logaddexp(a,b)` | $\ln(e^a+e^b)$ | 稳定的等价计算，不是 $\ln(a+b)$ |

### 配套例题：内积与外积不要混

若 $s=(1,2)^T$、$y=(3,4)^T$：

$$s^Ty=11,\qquad sy^T=\begin{pmatrix}3&4\\6&8\end{pmatrix}.$$

BFGS 分母用前者，矩阵修正项用后者。将两者混用可能触发维度错误，也可能由于广播机制产生“能运行但数学不对”的结果。

## 三、CSV 和 JSON 应该看哪些列

无约束实验通常记录：

| 字段 | 含义 |
|---|---|
| `k` | 迭代编号，初始点通常为 0 |
| `x` | 当前点 |
| `f` | 当前函数值 |
| `delta_f` | 与前一记录的绝对函数差，初始点没有前驱 |
| `grad_norm` | 当前梯度二范数 |
| `alpha` | 产生这次更新所用步长 |

实验一黄金分割还记录 `width`；三点法还记录 `x1/x2/x3/x_bar`。实验四记录 `working_set/direction/multipliers/event`。

### 现场例题：为什么 history 有 31 行，更新次数却是 30

第 0 行是初始状态，之后每次更新新增一行。所以黄金分割第一个函数 `len(history)=31` 时，更新次数是 30。

实验四更要区分“循环”“更新记录”和“真正移动点的次数”：VI 的删除约束轮点不动，最终检查轮也不动，不能把每一行都当一次位移。

## 四、状态字段应该怎样翻译

| 状态 | 准确解释 |
|---|---|
| `gradient_tolerance` | 达到梯度容差，仍需判断解的性质 |
| `iteration_limit` | 达到迭代上限，不等于达到精度 |
| `line_search_failed` | 当前线搜索未成功找到可接受步长 |
| `singular_hessian` | 牛顿方程因 Hessian 奇异等问题求解失败 |
| `nonfinite` | 迭代点出现 NaN 或无穷等非有限数值 |
| `unbounded_descent_ray` | 二次沿线曲率检查未通过，需分析该射线；不是对任意问题的全局无界证明 |
| `optimal`（有效集事件） | 在所用容差下通过当前 KKT 停止检查 |

### 现场例题：III 的远初值牛顿状态怎么汇报

建议说：“程序触发了梯度容差停止，但函数值约 0.999944，高于已证最优值 $\ln2$，没有得到正确极小点；Hessian 有负特征值，轨迹进入了平坦远区。”

不要把 `gradient_tolerance` 直接翻译成“全局最优”。

## 五、现场改题：改哪些内容才完整

### 1. 改目标函数

无约束问题需要同步目标函数、梯度，以及牛顿法使用的 Hessian。二次型还要同步用于精确步长的 $Q$。

### 现场例题：只改 f2 的交叉项会怎样

若把问题 II 交叉项从 $4x_1x_2$ 改成 $5x_1x_2$，则 $Q_2$ 的两个非对角元都应从 4 改成 5，梯度与 Hessian 也要一致。

而新矩阵行列式为 $21-25=-4$，不再正定！这时还必须重新分析是否有最小值，不能直接沿用正定二次型的结论和参考点。

### 2. 改初值

在 `run` 里改算例初值；有效集法还必须检查新点可行。无约束算法换初值也可能改变成功与否，III 就是直接例子。

### 现场例题：VI 能否把初值改成 $(100,100)$

不行，它违反 $2x_1+x_2\le3$ 等约束。当前教学实现会拒绝不可行初值，没有实现自动寻找初始可行点的阶段。

### 3. 改约束或常数

改约束要同步 `QP` 中的 $A,b$、初始点与约束编号说明；改目标常数要同步 `f6/f7` 与 `c0`。不改变梯度的常数也会影响报告中的函数值。

### 现场例题：VII 的常数从 9 改成 10

最优点、方向和乘子不变；最优值从 $1/9$ 变成 $10/9$。若只改显示函数不改问题数据，补充核验中的一致性检查应发现差异。

## 六、运行与核验：不要误覆盖已有结果

依赖已经安装时，可直接运行单个主程序。下面以另存结果为例：

```powershell
python "D:\user\download\zuiyouhua\实验二_最速下降法和牛顿法\code\main.py" --out "E:\学习相关\AI速成\.scratch\optimization-demo-exp2"
```

`--quiet` 只关闭过程显示，不改变算法。省略 `--out` 会写回该实验默认 `results`；根目录 `run_all.ps1` 会执行全部实验并核验，运行前应理解它会更新默认结果。

只核验目录已保存结果：

```powershell
python "D:\user\download\zuiyouhua\verify_all.py"
```

四个实验也各有 `code/verify.py`。它们读取默认 `results/results.json`，**不会因为你把主程序输出到另一个目录，就自动改去检查那个新目录**。

### 现场例题：跑了 --out，为什么 verify 还检查旧结果

因为输出参数只传给 `main.py`，验证脚本的读取路径是按自身位置构造的。比较另存结果时需要明确加载新路径，不能拿默认验证通过来冒充新路径已经被验证。

本次整理分别运行了现有结果的验证，并额外把四个主程序输出到工作区，对关键结果作对照；没有修改原实验算法或覆盖原结果。

## 七、模拟验收：可直接口头回答

### 1. 四个实验分别解决什么问题？

实验一研究一维搜索与选步长；实验二比较最速下降和基本牛顿；实验三用近似曲率和历史方向改进搜索；实验四在约束下通过调整工作集求二次规划最优解。

### 2. 为什么不直接固定一个很小步长？

不同方向、不同位置曲率不同。固定太大可能上升或发散，太小又慢；线搜索根据当前函数变化选择步长。

### 3. 黄金分割与三点法最本质的区别？

黄金分割靠单峰区间排除和固定比例收缩；三点法拟合函数形状，用抛物线顶点预测更好的位置。当前三点法不带黄金分割保底，两者停止条件也不同。

### 4. Armijo 条件是什么意思？

实际下降要达到线性预测的一定比例。它不要求沿线精确最优，也不自动保证拟牛顿的正曲率条件。

### 5. 为什么问题 II 不能说是非凸？

Hessian 对称，首主子式 21、行列式 5 均正，所以正定。它只是条件数大，最速下降相对慢。

### 6. 牛顿法为什么不直接求逆？

我们只需要逆矩阵作用在一个向量上的结果，解线性方程通常更稳定、更省计算，没必要先构造整个逆矩阵。

### 7. III 的远初值牛顿为什么必须保留失败结果？

它揭示基本牛顿和小梯度停止的局限。把失败结果改写成成功，会把实验最有价值的观察丢掉，也不符合数值证据。

### 8. BFGS 中的 H 是什么？

是逆 Hessian 近似，满足逆形式割线条件 $H_{k+1}y_k=s_k$；不是解析 Hessian。

### 9. PRP+ 为什么仍需要检查下降性？

beta 非负只是一个保护，并不独立保证组合方向在所有情况下下降。程序还做方向检查和周期重启。

### 10. V 是三维，为什么不要求三步结束？

最多 $n$ 步属于正定二次型线性 CG 的理想结论；V 是非线性函数，使用 Armijo 和重启，条件不同。

### 11. 有效集方向为零为什么还要继续？

当前工作集可能过度限制。如果乘子有负值，放开相应边界仍能下降，所以要删负乘子约束。

### 12. 有效约束的乘子一定大于零吗？

不一定，可以等于零。互补松弛只保证非有效约束乘子为零，不能反推所有有效约束都严格正乘子。

### 13. VI 最后哪些约束有效？

第 1、3 条，交点是 $(4/3,1/3)$；对应乘子 $22/9$、$1/9$ 非负，满足 KKT。

### 14. 为什么既做解析检查又调用 SciPy？

解析结构提供可解释的真值，独立求解器提供另一条实现路径，两者互相补充。SciPy 不是替代核心实验算法，也不是对所有问题的数学证明。

### 15. 你怎么判断一次实验真的成功？

先看是否达到停止标准，再看目标值、解的位置、问题结构和独立核验；约束问题检查四项 KKT。仅看状态字符串、曲线变平或打印出一个数都不够。

## 八、最后一轮自测

合上资料，应能独立完成：

- 从 $f(x+\alpha d)$ 推导二次型精确步长。
- 对问题 II 写出梯度、Hessian，判正定并解出 $(2,-11)$。
- 解释 III 的唯一全局最优点与远初值牛顿非最优停止。
- 写出 $s,y$ 的定义和两种割线条件，分清 $H$ 与 $B$。
- 手算一次 DFP 或 BFGS 更新，并检查 $H_+y=s$。
- 手算一次 PRP+ beta，并判断方向是否下降。
- 按 $Ax\ge b$ 写出四项 KKT，推导阻挡比值。
- 不看答案复述 VI 的“删4、加1、删5、加3、最优”。

背诵优先级是“能解释公式的作用和前提”高于“记住很多小数”。迭代次数可帮助对照当前运行，但换初值、容差、算法变体或数值环境后可能改变。
