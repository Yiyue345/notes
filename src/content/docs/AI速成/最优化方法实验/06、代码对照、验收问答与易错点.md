这篇不要求逐字背。打开代码或准备验收时，用它查：**该点哪里、变量叫什么、输出应该怎样解释。**

## 1. 先分清 main 和 methods

每个实验目录大致是：

```text
实验目录/
├── code/
│   ├── main.py             题目、初值、运行入口、保存结果
│   ├── verify.py           核验脚本
│   └── methods/            每种算法的具体实现
├── results/                JSON、CSV、图与日志
└── requirements.txt        需要的 Python 依赖
```

例如实验三 `main.py` 定义 `f4/g4` 和 `f5/g5`，再调用 `methods/bfgs.py`、`dfp.py`、`conjugate_gradient.py`。**看题目先打开 main；看算法步骤再打开对应 methods 文件。**

### 例子：老师问“BFGS 公式在哪里”

先在 [实验三 main.py](/downloads/optimization/实验三_拟牛顿法和共轭梯度法/code/main.py) 认识目标函数与初值，再打开 [bfgs.py](/downloads/optimization/实验三_拟牛顿法和共轭梯度法/code/methods/bfgs.py) 的 `bfgs()`，找到 `s`、`y`、`sy` 和 `H` 的更新。不需要在 `main.py` 中寻找全部矩阵公式。

## 3. 常用变量速查

| 代码 | 数学含义 | 怎么理解 |
|---|---|---|
| `f`、`fx` | $f$、$f(x)$ | 目标函数、当前目标值 |
| `x0`、`x`、`xn` | $x_0,x_k,x_{k+1}$ | 起点、当前点、下一点 |
| `g`、`gx`、`gn` | 梯度函数、$g(x)$、$g(x_{\rm new})$ | 函数与计算结果要分开；Armijo 参数 `g` 已是数值或向量 |
| `d`、`alpha` | $d_k,\alpha_k$ | 搜索方向与步长 |
| `hess`、`Q` | Hessian 函数、二次型 Hessian | 二阶曲率；`Q` 在二次题里固定 |
| `H` | Hessian 的逆近似 | BFGS、DFP 用于求 $d=-Hg$ |
| `s,y,sy` | $x_{k+1}-x_k$、$g_{k+1}-g_k$、$s^Ty$ | 走过距离、梯度变化、两者点积 |
| `beta` | PRP+ 的历史方向系数 | 0 表示只用新的负梯度 |
| `A,b,slack` | $Ax\ge b$、$Ax-b$ | 约束及每条约束剩余量 |
| `W,AW,lam` | 工作集、$A_W$、$\lambda_W$ | 当前锁住的约束、矩阵行、对应乘子 |
| `tol,max_iter` | 容差、迭代上限 | 何时认为足够小、最多试多少次 |

**同名不一定同义。** 例如黄金分割法中的 `d` 是一维内部试探点，不是多维算法中的方向；插值法里的 `f1` 是第一个试点的函数值，而实验二 `main.py` 的 `f1` 是问题 I 的函数。

### 例子：`g` 到底是函数还是值

```python
gx = g(x)
alpha = armijo(f, x, gx, d)
```

第一行 `g` 是函数、`gx` 是向量；第二行把向量 `gx` 传进去后，Armijo 函数内部把这个参数命名为 `g`。所以一定要看**当前函数的参数和赋值**。

## 4. 一维搜索变量

| 变量 | 意思 |
|---|---|
| `a,b` | 当前搜索区间左右端点 |
| `m` | 进退法返回的三个点中间位置，不一定是区间算术中点 |
| `tau` | 黄金分割比例 $(\sqrt5-1)/2\approx0.618$ |
| `c,d,fc,fd` | 黄金分割的两个内部点以及对应函数值 |
| `x1,x2,x3` | 抛物线插值三个试点 |
| `B1,B2,B3,C1,C2,C3` | 课件三点插值公式中的六个中间项 |
| `B,C,D,quad_a,x_bar` | B 项之和、C 项之和、三点位置乘积、二次项系数 $-C/D$、预测顶点 $B/(2C)$ |
| `alpha0,rho,c1` | Armijo 初始步长、回溯缩小比例、充分下降系数 |

### 例子：`rho=0.5` 有什么用

若 `alpha0=1`，每次回溯令 `alpha *= rho`，候选步长依次为 $1,0.5,0.25,0.125,\ldots$。一旦满足 Armijo 条件就返回，不必每次都缩到很小。

## 5. 结果文件怎么看

| 字段或文件 | 内容 | 易错提醒 |
|---|---|---|
| `results.json` | 结果、状态、完整迭代历史 | 先确认是否由当前代码生成 |
| `*.csv` | 一行一轮的记录 | 第 0 行通常是初始状态 |
| `k`、`iterations` | 轮次、更新次数 | 初始行不算一次更新 |
| `f`、`delta_f` | 函数值、相邻两次函数值差 | 小函数差不是最优证明 |
| `grad_norm` | 梯度范数 | 小梯度也可能出现在平坦远区 |
| `status` | 代码触发的停止原因 | `gradient_tolerance` 不是“已证明全局最优” |
| `working_set`、`multipliers` | 工作集及其对应乘子 | 两个列表按工作集顺序对应 |
| `kkt` | 可行、对偶、驻点、互补残差 | 四项都要检查 |

### 例子：为什么 31 行只有 30 次更新

第 0 行是初始点，第 1 至 30 行才是更新后记录，所以历史有 31 行、更新次数为 30。有效集法的删除约束轮次甚至不移动位置，因此还要区分循环次数与实际移动次数。

## 6. 怎样运行，又不覆盖原结果

先使用实际安装了 NumPy、SciPy、Matplotlib 等依赖的 Python。正常在某个实验目录运行 `python code/main.py` 会写默认 `results/`。只想另存一次结果，可以显式指定 `--out`：

```powershell
python "D:\user\download\zuiyouhua\实验二_最速下降法和牛顿法\code\main.py" --out "E:\学习相关\AI速成\.scratch\optimization-demo-exp2"
```

加 `--quiet` 只是不显示过程，不是“只读模式”；程序仍会输出文件。`run_all.ps1` 会运行全部实验并更新默认结果。静态 Word 报告不会自动跟随更新。

独立核验保存的默认结果：

```powershell
python "D:\user\download\zuiyouhua\verify_all.py"
```

### 例子：另存到 --out 后，验证脚本检查哪里

现有 `verify_all.py` 和各实验 `verify.py` 默认读取原实验目录下的 `results/results.json`，不是自动读取你传给 `--out` 的目录。所以测试通过不自动代表另存结果已经被脚本检查；需要明确加载另存数据。

## 7. 老师可能问什么

下面是练习问答，不代表真实考题。

**问：实验一四种方法各做什么？** 进退法先找候选区间；黄金分割缩区间；三点插值拟合并预测顶点；Armijo 给已有下降方向选择步长。

**问：为什么选负梯度？** 在当前点附近、固定欧氏方向长度时，它是一阶意义下最陡的下降方向；步长仍需另选。

**问：牛顿法和最速下降有什么区别？** 最速下降主要用梯度，牛顿法还利用 Hessian 曲率；前者每步较简单，后者对基本二次题可能一步到解，但一般题不一定下降。

**问：为什么 II 是正定？** $Q_2$ 的第一个顺序主子式是 21，行列式是 5，均为正，所以它是正定矩阵。

**问：III 的远初值牛顿停止了，为什么不说成功？** 它走到平坦远区，小梯度满足停止条件，但函数值约 0.999944，与真正最优值 $\ln2$ 相差约 0.3068。

**问：BFGS 与 DFP 的 H 是什么？** 它们都维护逆 Hessian 的近似，并用 $s$、$y$ 更新；两者更新公式不同。

**问：PRP+ 的加号什么意思？** 把计算出的 PRP 系数截断为非负数。代码还每 $n$ 步重启，并检查方向是否下降。

**问：有效集法中的零方向能直接停吗？** 不行。还要看工作集乘子；按当前符号约定，若有负乘子应删除相应约束。

**问：VI 的工作集怎样变化？** 从 $\{4,5\}$ 开始，依次删 4、加 1、删 5、加 3，最终 $\{1,3\}$。

**问：如何判断约束解是否可信？** 检查可行、乘子非负、驻点条件、互补松弛四项 KKT；本实验正定且约束线性，因此满足这些条件的可行点是唯一全局最优。

## 8. 考前最后五分钟

1. 写出 $x_{k+1}=x_k+\alpha_kd_k$，分别指出方向与步长。
2. 讲清每个实验的求解方法，别把验证求根器当成核心算法。
3. 能定位 `main.py` 的题目和 `methods/` 的算法。
4. 解释 III 的小梯度非最优停止，说明为什么不能只看状态。
5. 会复述有效集的“零方向查乘子、非零方向查阻挡”。
