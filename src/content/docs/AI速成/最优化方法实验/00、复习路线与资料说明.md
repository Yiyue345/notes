## 二、四个实验之间的关系

```text
共同目标：让目标函数变小，同时满足问题的条件
|
+-- 无约束优化
|   |
|   +-- 选方向：负梯度 / 牛顿 / 拟牛顿 / 共轭梯度
|   +-- 选步长：精确线搜索 / Armijo 回溯
|   +-- 检查：梯度、函数值、参考解、曲率与状态
|
+-- 约束优化
    |
    +-- 保持可行：不能走出约束围成的区域
    +-- 选方向：当前工作集上的等式约束子问题
    +-- 调整边界：阻挡时加入，负乘子时删除
    +-- 检查：KKT 的四项条件
```

最重要的统一表达式是：

$$
x_{k+1}=x_k+\alpha_kd_k.
$$

其中 $d_k$ 决定“往哪里”，$\alpha_k$ 决定“走多远”。实验四还必须保证走完后依然可行。
